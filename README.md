# mdviewer

一个零构建的 Markdown 阅读器，双击即用。支持 LaTeX 公式渲染、代码高亮、Mermaid 图表、图片渲染、页内锚点跳转、跨文件链接、主题切换与目录导航。可选 Tauri 桌面/移动应用包装。

## 快速开始

直接双击 `web/index.html` 在浏览器中打开即可使用。无需安装、无需构建、无需服务端。

> 前端全部为静态文件，也可部署到任意静态托管（Cloudflare Pages 等）。

## 使用方式

### 打开文件
- 点击工具栏 **「打开」** 按钮选择 `.md` 文件
- 或将文件/文件夹拖入窗口
- 快捷键 `Ctrl+O`（macOS: `Cmd+O`）

### 打开文件夹
- 点击 **「文件夹」** 按钮选择目录，自动扫描所有 `.md` 文件
- 或直接拖入文件夹
- 侧栏「文件」页签以树形结构展示目录和文件，点击切换

### URL 导入
- 点击 **「URL」** 输入远程 Markdown 文件的直链地址
- 支持 raw.githubusercontent.com 等公开源

### 侧栏
点击 **「侧栏」** 打开/关闭左侧面板，包含两个页签：
- **文件** — 打开文件夹后显示树形文件列表
- **目录** — 自动从文档标题生成，滚动时高亮当前章节

### 选项
点击 **「选项」** 打开设置面板：

| 选项 | 说明 |
|------|------|
| 主题 | 浅色 / 深色 / 护眼 / Nord / Gruvbox / Monokai / Solarized / Solarized Dark / 自定义 |
| 自定义颜色 | 自定义主题下可独立调整背景、文字、标题、链接、代码背景、边框颜色 |
| 代码高亮 | 自动跟随 / 强制浅色 / 强制深色 |
| 字号 | 12–48px 滑块 |
| 侧栏字号 | 10–24px 滑块 |
| 行高 | 1.3–2.2 滑块 |
| 字体 | 无衬线 / 衬线 / 等宽 |
| 内容宽度 | 窄 / 中 / 宽 / 全宽 |
| 永不隐藏顶栏 | 勾选后顶栏始终显示，不随滚动自动隐藏 |
| 侧栏选项卡调换 | 勾选后将「目录」与「文件」页签位置互换 |
| 滑动打开侧栏 | 移动端是否启用侧栏触摸滑动手势（默认开启） |
| 保存会话 | 关闭后重新打开时自动恢复上次浏览位置（默认开启） |
| 自动暗色模式 | 跟随系统颜色，在浅色/深色主题间自动切换（仅 light/dark 主题时生效，默认关闭） |
| 快捷键 | 8 个操作（打开文件、打开文件夹、切换侧栏、打开 URL、打开选项、增大字号、减小字号、关闭面板）均可自定义快捷键 |

### 内容缩放

支持两种方式调整阅读区字体大小（不影响侧栏和工具栏）：
- **触摸双指捏合** — 移动端双指缩放，范围 50%–300%；双击重置为 100%
- **快捷键** — `Ctrl+=` / `Ctrl+-` 缩放（桌面端，调整的是整体字号）
- 缩放后右下角显示当前百分比按钮，点击重置

## 支持的语法

### Markdown
- 标题（`#` ~ `######`）
- 粗体、斜体、删除线
- 有序/无序列表
- 链接、图片（自动懒加载）；点击图片可放大查看，Esc 或再次点击关闭
- 引用块
- 表格（斑马条纹）
- 水平线
- 内联代码 / 围栏代码块（自动语法高亮，支持 190+ 语言）

### LaTeX 公式
支持四种定界符，适用于行内公式和独占公式：

| 定界符 | 类型 | 示例 |
|--------|------|------|
| `$...$` | 行内 | `$E=mc^2$` |
| `$$...$$` | 独占 | `$$\sum_{n=1}^\infty \frac{1}{n^2}$$` |
| `\(...\)` | 行内 | `\( \vec{F} = m\vec{a} \)` |
| `\[...\]` | 独占 | `\[ \int_a^b f(x)\,dx \]` |

> `$` 后跟空白（如 `$ x^2 $`）也能正常识别，但会被视为行内公式。

### Mermaid 图表
- ```` ```mermaid ```` 代码块自动渲染为 Mermaid 图表
- 支持流程图、时序图、甘特图、类图等

### 图片
- `![alt](图片地址)`，支持 http(s) 绝对链接与相对路径
- 相对路径按 Markdown 文件所在位置解析：
  - **URL 导入** — 相对于该 md 的 URL
  - **桌面版** — 直接读取本地磁盘（包括 `../` 上级目录）
  - **文件夹模式** — 从已打开的文件夹中按相对路径查找（浏览器 / Android 均可）
  - **单文件模式** — 浏览器无法读取同目录文件，会显示带说明的占位框
- 点击图片进入灯箱放大，`Esc` 或点击任意位置关闭
- 图片加载失败时显示占位框，包含 alt 文本、原始路径与原因提示

### 页内锚点
- 支持 `[文字](#锚点)` 跳转到文档内标题，自动避开顶部工具栏
- 锚点匹配依次尝试：精确 id → slug 变体 → 标题文字（大小写与标点不敏感）
- 标题可自定义 id：`## 标题 {#custom-id}`，之后用 `[文字](#custom-id)` 引用
- 支持 `#中文标题`、`#Title-Case`、URL 编码形式（`#%E6%A0%87%E9%A2%98`）
- 不存在的锚点不会跳转，链接会加虚线标记提示
- 建议：标题自动生成的 id 规则为「小写 + 标点转 `-`」，保留中文

### 跨文件链接
- 支持链接到其它 Markdown 文档：相对路径（`./sub/other.md`、`../other.md`）与绝对路径（`C:\docs\other.md`、`/abs/path/other.md`）
- 也支持 `file://` 前缀与 URL 编码（`my%20doc.md`）写法
- 跨文档锚点：`[文字](other.md#章节)` — 目标文档渲染完成后自动定位到对应标题
- 路径基准随文档切换自动更新（跳转后文档内的相对链接与相对图片继续正确解析）
- 各端行为：
  - **桌面版** — 相对路径以当前文档所在目录为基准；绝对路径直接读取；非 Markdown 文件（如 PDF）交给系统默认程序打开
  - **文件夹模式（桌面 / Android）** — 在已打开的文件夹内按相对路径查找，文件树高亮同步到目标文件
  - **浏览器文件夹模式** — 在已加载的文件列表内按相对路径查找
  - **URL 导入** — 相对地址相对于该 Markdown 的 URL 解析
- 跨文件链接在正文中带 ↗ 标记与点状下划线，便于与普通链接区分

### 其他渲染特性
- 标题自动生成锚点，鼠标悬停显示 `#` 链接
- 外部链接在新标签页打开（`target="_blank"`）；页内锚点与相对链接不会
- 代码块圆角阴影
- 打印时自动隐藏工具栏和侧栏

## 桌面应用 (Tauri)

`application/` 目录包含 Tauri v2 桌面包装，支持 Windows / macOS / Linux。

桌面版额外特性：
- **原生命名对话框** — 通过 `tauri-plugin-dialog` 打开文件/文件夹，获取真实路径
- **拖放恢复** — 将文件或文件夹拖入窗口，路径自动保存到本地会话
- **文件关联** — 在安装包中注册 `.md` / `.markdown` / `.mdown` 扩展，双击直接打开
- **会话持久化** — 关闭后重新打开，自动恢复上次浏览的文件/文件夹（含侧栏状态），恢复时显示 Toast 提示
- **外部链接** — 点击 Markdown 中的 `http(s)://` 链接，自动在默认浏览器中打开

### 开发

```sh
cd application/src-tauri
cargo tauri dev
```

### 构建安装包

项目根目录一键构建（自动升级版本号 + 同步前端 + 编译）：

```bat
build.bat
```

或直接调用 PowerShell 脚本：

```powershell
.\build.ps1
```

或手动分步执行：

```sh
cd application/src-tauri
cargo tauri build
```

Windows 下生成 NSIS 安装包（`.exe`），位于 `target/release/bundle/nsis/`。

### 前端目录

`web/` 是唯一的前端目录，浏览器版与 Tauri 桌面/移动端共用，无需任何同步或复制步骤。
修改 `web/` 下的文件后，重新执行构建即可（`build.ps1` 会自动写入版本号）。

## 移动端 (Android)

`application/` 目录同样支持 Tauri v2 的 Android 构建。

Android 端额外特性：
- **文件选择** — 通过 `tauri-plugin-dialog` + 浏览器 FileReader 打开 `.md` 文件
- **文件夹浏览** — 通过 `tauri-plugin-scoped-storage` 使用 SAF `ACTION_OPEN_DOCUMENT_TREE` 选择目录，支持递归浏览与文件切换
- **侧栏滑动手势** — 从屏幕左侧边缘右滑打开侧栏，在侧栏上左滑关闭
- **触摸缩放** — 双指捏合缩放内容区，双击重置
- **底部操作面板** — 工具栏仅保留「菜单」按钮，其余操作收纳在底部弹出面板
- **会话持久化** — 使用 scoped-storage 持久化 handle ID，重启后自动恢复文件夹视图
- **安全区域适配** — CSS `env(safe-area-inset-*)` 适配刘海屏

### 构建

```sh
cd application/src-tauri
cargo tauri android build --apk
```

构建产物位于 `src-tauri/gen/android/app/build/outputs/apk/`。

## 技术栈

全部由 CDN 引入；本地代码是多文件、无打包步骤（传统 `<script>` 顺序加载，共享全局作用域，因此 `file://` 双击仍可用）。

| 库 | 用途 | 版本（锁定） |
|----|------|-------------|
| [marked](https://marked.js.org/) | Markdown 解析 | 15.0.12 |
| [KaTeX](https://katex.org/) | LaTeX 公式渲染 | 0.16.11 |
| [highlight.js](https://highlightjs.org/) | 代码语法高亮 | 11.9.0 |
| [Mermaid](https://mermaid.js.org/) | 图表渲染 | 11.16.0 |

## 界面布局

```
┌──────────────────────────────────────┐
│  mdviewer     [打开] [文件夹] [URL] … │ ← 顶栏（滚动时可隐藏，上滑恢复）
├────────┬─────────────────────────────┤
│        │                             │
│ 侧栏   │       Markdown 内容         │
│ 文件   │       (居中阅读区域)         │
│ 目录   │                             │
│        │                             │
└────────┴─────────────────────────────┘
```

- 侧栏：`position: sticky; top: 48px; height: calc(100dvh - 48px)`，面板独立滚动（`min-height: 0` + `overflow-y: auto`），与页面滚动互不影响
- 顶栏：上滑滑入，下滑滑出，支持「永不隐藏」选项
- 内容区：居中，最大宽度可调

## 兼容性

支持所有现代浏览器（Chrome、Edge、Firefox、Safari）。文件夹拖放功能在 Chrome/Edge (WebView2) 下体验最佳。

## 文件结构

```
mdviewer/
├── build.ps1                        # 一键构建脚本（PowerShell）
├── build.bat                        # 一键构建批处理（调用 build.ps1，自动绕过策略）
├── web/                             # 前端目录（浏览器版与 Tauri 共用）
│   ├── index.html                   # 页面骨架
│   ├── app.css                      # 全部样式（含 9 套主题变量）
│   ├── js/
│   │   ├── core.js                  # 主题色板、全局 state、设置与会话持久化、快捷键
│   │   ├── theme.js                 # 主题应用与设置面板同步
│   │   ├── markdown.js              # marked 配置、LaTeX 预处理、标题自定义 id
│   │   ├── links.js                 # 页内锚点解析与跳转
│   │   ├── media.js                 # 图片相对路径解析、失败占位、灯箱
│   │   ├── render.js                # 渲染管线、标题锚点、目录构建
│   │   ├── file.js                  # 文件/文件夹加载、文件树
│   │   ├── nav.js                   # 跨文件链接：相对/绝对路径解析与跨文档锚点跳转
│   │   ├── ui.js                    # 侧栏、URL 导入、字号、面板开关
│   │   └── init.js                  # 应用装配、事件绑定、移动端手势
│   ├── sw.js                        # Service Worker（离线缓存用）
│   ├── manifest.json                # PWA 清单
│   └── favicon/icon-*.png           # 站点图标
├── application/                     # Tauri 桌面+移动应用包装
│   └── src-tauri/                   # Rust + Tauri 源码（frontendDist 指向 ../../web）
│       ├── Cargo.toml
│       ├── tauri.conf.json
│       ├── icons/                   # 应用图标
│       ├── capabilities/            # 权限配置（opener, dialog, scoped-storage）
│       └── src/                     # Rust 入口 + 命令（read_file, scan_folder, is_dir, read_image, resolve_doc_path）
└── README.md                        # 本文件
```

> 脚本按 `core → theme → markdown → render → file → ui → init` 顺序加载于同一全局作用域，
> 顺序不可调整（后加载的脚本依赖先加载的顶层声明）。
